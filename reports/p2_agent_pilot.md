# P2 Agent 端到端评测（2026-10-21）

## 范围和分母

固定选中 2 例；已尝试 2，确认通过 1，失败 1，待人工语义复核 0，未执行 0。
保守确认成功率：0.5（通过数 / 已尝试数；待复核也保留在分母）。

未执行案例不进入已尝试分母；失败、超时和待复核不得静默剔除。回复文本正确但无工具/DB 证据不判成功。
